Agent connections

Use JobForge inside your agent.

Each connection is bound to one profile and grants only the scopes you approved. The host agent supplies the model; JobForge supplies local state, validation, rendering, and approvals.

Review approvals

Install or repair an agent

Run this in a terminal. The wizard detects your agents, shows the exact config and skill paths, backs up host configs, and registers the MCP server. No model provider is required.

npx jobforge

Supported: Claude Code, Codex, Pi, Hermes, OMP, and generic MCP. Optional Chromium and Typst installs are separate consent prompts.
