What GitHub context does

  1. Syncs repository names, descriptions, languages, topics, stars, and last-push dates.
  2. Fetches the README for a repository when you open it, and extracts a few suggested bullets from overview/features sections.
  3. Lets you edit the project name, tech line, bullets, and tags before anything enters the project bank.
  4. Adds detected skills to your profile and rescored existing jobs when you confirm an import.

The resume renderer only uses the bullets you approve. GitHub metadata is context, not a claim; nothing is auto-added to a resume or application.
